# 美食工坊

奶油色食品自动化游戏：连接多条生产线，让美食自动上架，拖给猫猫顾客，再招员工接手送餐。

[打开游戏](https://nornttyy.github.io/food-factory/) · [GitHub 仓库](https://github.com/Nornttyy/food-factory)

## v0.14.0：独立营业区、顺滑动作与常驻配方

- 顾客和员工不再装在带边框的列表里，改为右侧整片营业场景：地面、三个等餐位、取餐台、员工活动空间。所有猫猫共用场景绘制，按钮只保留透明点选/拖放热区；员工不再是固定头像。

## 玩法

- 自由放置设备，拖动铺传送带，支持分流、合流与多条产线。
- 面粉 → 和面 → 烘烤，制作面包；订单解锁甜甜圈和橙汁。
- 成品先上货架，玩家拖给猫猫；招募员工后自动送餐。领取订单奖励，升级机器并扩建地块。
- 初始赠送设备可免费收回重放，拆除清空物品；付费设备退回实付费用。
- 堵塞停工、不丢料；支持暂停、2 倍速和浏览器自动存档。没有离线收入。

## 大地图与仓储合作

- 开局开放 14×8 格，五次扩建依次到 18×10、22×12、28×16、34×20、40×24，最大 960 格（原最大 112 格）。扩建花费 350 / 900 / 1800 / 3600 / 6500 金币。旧存档原前三档直接获得更大的区域，设备位置、实付费用和订单进度不变。
- 镜头保持局部可操作大小，扩建不重置视角或缩小机器；「地图」打开可点选、方向键移动的小地图，「查看全图」看整体布局，百分比按钮回到起步区。屏外产线仍然生产。绘制使用逐帧坐标索引和可见范围裁剪，不逐台线性查邻居。
- 所有产线接入货物架。送餐赚金币并推进订单；点货架可把成品移入共享仓库，仓满时留在货架，不超收、不丢料。有食物的货架不能拆；空架回收不会影响仓库或员工已取出的餐点。
- 主菜单或工坊入口「仓库与商店合作」提供 3 张无期限合作货单，按解锁阶段分别要求早餐、烘焙组合、冷饮、蛋糕或全部 8 种食品。备齐后一次扣货、领取批发溢价和声望，再刷新选择；旧按钮不能重复发货。精品包装研究对现卖、散卖和合作结算均有效。
- 声望达到 3 / 9 / 18 / 30 后，仓储从 100 增至 150 / 200 / 250 / 300 份，并提升合作报价。最多一单需求 96 份，不会超过初始容量；可散卖库存腾出空间。合作及库存散卖不计入普通订单、急单或累计现卖份数，避免旧库存绕过限时任务。
- 6 个长期目标覆盖首次合作、多种食品、声望、全菜单、扩建和综合经营，奖励金币与研究点；目标只能领取一次。每种食品显示库存和累计合作发货数，方便安排补货。
- 仓储、合作历史、声望、货架库存、顾客、员工手持食物及领奖状态均写入原浏览器存档。旧存档自动补充空白记录；练习工坊仍完全隔离，不操作真实库存。

## 新食物与新手练习

- 奶油饼干（8 金币）、奶香包（9）、草莓蛋糕（16）、橙汁冰棒（17），连同原有食品共 8 种可出售成品。每种新食物都有独立生成素材和加工设备，沿用 Q 弹反馈；配方辅料由设备自带。
- 面团 → 曲奇烤炉 → 饼干，开局可建；面团 → 小蒸笼 → 奶香包，第 1 单后开放；面团 → 蛋糕工台 → 草莓蛋糕，橙汁 → 冰棒冷柜 → 冰棒，第 2 单后开放。面团和果汁可用分流器制作支线。
- 配方手册展示全部 8 条路线、基础售价和解锁条件。前 4 张订单后新增 4 张新品订单，此后轮换全部食品；旧存档已接的订单原样保留，领取后才切换新版目录。已接急单不变。
- 第一次开始经营会进入独立的新手练习：选传送带、补接空格、拖食物给猫猫、升级烤箱、送满 4 份领取订单。小卡片和高亮格子引导实际操作，不使用遮挡画布的大弹窗。
- 练习可以随时跳过、重练；主菜单「新手练习」与帮助页「跟着练一次」可重播。练习暂停正式工坊的生产与急单计时，不花正式金币、不保存练习布局；退出或刷新回到原工坊，老玩家不会被强制教学。

## 主菜单、急单与研究

- 启动先进入主菜单：开始 / 继续经营、急单与研究、配方手册、游戏设置。工坊左上角招牌可保存并返回菜单。菜单内不生产，且不会穿透建造、旋转或删除操作。
- 急单三选一，随主订单解锁早餐、甜点、双拼和三线协作等 9 种基础挑战，完成多次后增加需求。只统计接单后的成品销售，普通收入与主订单进度照常保留。轻松单适合初始产线，产能单需要升级或多条流水线。
- 达标领取额外金币与 1–3 个研究点。超时或放弃不扣金币；达标待领奖不会过期。同一时间只可接受一个急单。使用模拟时间计时，2 倍速同时加快生产和倒计时；菜单、弹窗、后台及暂停时均停止计时。
- 永久研究分为高效加工（每级 +15% 速度）、轻快运输（每格 1.2 → 1.1 → 1.0 → 0.9 秒）和精品包装（每级售价 +10%，按件取整）。每条最多 3 级，分别花费 1 / 2 / 3 点；升级保留正在加工及运输的完成比例，出货站速度只随自身等级改变。
- 重开需要确认，先备份、保存成功才替换工坊；主菜单可恢复重开前的存档。研究、急单与设置都会保存。旧版存档自动补充空的研究记录，不重置设备、金币或进度。

## 视野与 Q 弹反馈

- 画布铺满窗口，右侧保留窄顾客区。订单、设备详情默认收起；建造卡片按需展开，选中后自动收起。打开面板只覆盖局部，不缩小画布或重置视角。
- 默认取景约 10×6 格，扩建后保持机器可操作大小。滚轮或加减按钮缩放，✥ 模式或鼠标中键拖动，百分比按钮返回起步区；地图可定位远处产线，⛶ 进入可拖动的纯净视野。
- 放置设备有落地压扁和阻尼回弹，加工有节奏挤压，货物跳动前进，出货和升级有局部粒子及金币反馈。反馈不晃动镜头、不改变生产速度，不进入存档。
- 暂停后仍可编辑布局。帮助内可以关闭 Q 弹；默认尊重系统“减少动态效果”设置。平板/手机使用单指放置，多指触摸会取消待放置操作，不支持双指捏合。

## 传送带连接

- 选中传送带工具，可以从旧传送带继续拖线；转弯会调整上一格出口，只为新增格子付费。
- 接入已有的侧向传送带时保留它的下游方向；明确拖过相对的传送带，会将其改为本次拖线方向。可拖过机器并沿它的既有出口继续铺，只有出货站会结束本次拖线。
- 拉错机器方向时保留最后有效格，不必松手，改沿出口拖动即可继续；快速斜拖优先经过固定设备的出口，不会自动旋转机器或清空原料。
- 箭头是出口，不能同时进料；两条出口相对的带子不会来回传货。分流器有两个出口，合流器可从其他三侧进料，出货站四侧均可接入。
- 轨道按实际接口绘制，转角不多画接口；方向不通的相邻端口用短红线标识。运输、拖线和绘制共用 `src/factory-links.js`。
- 机器、料斗和出货站的有效连接都有接驳段，延伸至格边并与传送带对齐。接口固定在底座上，不随机身 Q 弹缩放；邻居旋转或拆除时即时重算。
- 旧存档不重置。旧布局若从机器出口侧喂料，需要旋转机器或改从其他侧接入。
