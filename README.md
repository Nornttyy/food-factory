# 美食工坊

奶油色猫咪经营游戏：零金币开店，亲手做饭并给顾客送餐，再招猫咪员工、搭建食品自动化产线。没有真实纹理，没有离线收入。

[打开游戏](https://nornttyy.github.io/food-factory/) · [GitHub 仓库](https://github.com/Nornttyy/food-factory)

## 猫咪开店

- 新游戏 0 金币、没有免费自动化设备；小店的手工作台和原料永久免费，不能被拆除。菜单中的「重新开一间」需确认，并保留可恢复的旧存档。
- 点「做一份」或工作台，猫咪走过去加工；做好会放进 24 格取餐架。点「取餐」端起，再点顾客或「送餐」，实际走到顾客面前才扣掉一份食物并收钱。直接点有现货的顾客也会先取餐再送餐。
- 点顾客可选中其缺少的食谱；点击地面控制走路，画布聚焦时也可用方向键 / WASD，E / Enter 做饭、取餐或送餐。顾客不催单、不扣钱；送餐后 5 秒补位。
- 做错餐时可放回餐架，或点「退回原料」消耗手里的 / 餐架里的一份食物，释放空间，不返金币。即使仓库和餐架都满了，0 金币也能继续做顾客需要的餐。
- 服务 6 位顾客开放自动化产线；服务 12 位可花 120 金币招跑堂猫，服务 24 位可花 200 金币招后厨猫。一次性费用，无工资扣款。跑堂负责实际取送餐，后厨按缺少的点单逐份手作；后厨耗时为玩家的 1.6 倍，升级机器和多条产线更适合批量备货。
- 猫咪小店和自动化工坊是同一个存档中的两个场景，共享金币、食品和订单。切换不会暂停生产，主菜单、弹窗、后台及暂停会冻结全部角色和生产。小店不占用旧地图格子。
- 食品售价现为面包 4、饼干 5、原味甜甜圈 6、草莓甜甜圈 8、奶香包 6、橙汁 6、蛋糕 10、冰棒 11。运输售价为传送带 35、分流器 140、合流器 100、出货站 160。
- 新工坊订单奖励为旧目录的 1/10（首单 38）；新接急单奖金为原来的 1/4，期限加倍，研究点不变。旧存档已接的普通订单和急单保留原要求、奖励和期限，下一单切换新平衡。
- 旧存档金币、设备、实付退款、研究和库存保留，不清空；立即开放产线及员工购买。旧产线同样不再自动售卖，需要回小店手送或购买跑堂猫。想体验零金币开局，可备份后重开。

## 自动化产线

- 自由放置设备，拖动铺传送带，支持分流、合流与多条产线。
- 面粉 → 和面 → 烘烤，制作面包；订单解锁甜甜圈和橙汁。
- 成品运到小店取餐架，由玩家或跑堂猫送给顾客；升级机器、分流备货并扩建地块。
- 旧版赠送设备仍可免费收回重放，拆除清空物品；付费设备只退回历史实付费用，不按涨价后的价格退款。
- 堵塞停工、不丢料；支持暂停、2 倍速和浏览器自动存档。没有离线收入。

## 大地图与仓储合作

- 开局开放 14×8 格，五次扩建依次到 18×10、22×12、28×16、34×20、40×24，最大 960 格（原最大 112 格）。扩建花费 350 / 900 / 1800 / 3600 / 6500 金币。旧存档原前三档直接获得更大的区域，设备位置、实付费用和订单进度不变。
- 镜头保持局部可操作大小，扩建不重置视角或缩小机器；「地图」打开可点选、方向键移动的小地图，「查看全图」看整体布局，百分比按钮回到起步区。屏外产线仍然生产。绘制使用逐帧坐标索引和可见范围裁剪，不逐台线性查邻居。
- 点出货站选择「送到小店」或「入库」；默认送到 24 格共享取餐架，不立刻加钱。给顾客送餐才推进工坊订单和急单。入库不算销售，所有入库站共享仓库。架满 / 仓满停收；并发到货预留容量，不超收、不丢料。拆除出货站不清空共享库存。
- 服务 30 位顾客后，「仓库与商店合作」开放 3 张无期限合作货单，按解锁阶段要求早餐、烘焙组合、冷饮、蛋糕或全部 8 种食品。备齐后一次扣货、领取批发溢价和声望，再刷新选择；旧按钮不能重复发货。精品包装研究对顾客售价和合作结算均有效。
- 声望达到 3 / 9 / 18 / 30 后，仓储从 100 增至 150 / 200 / 250 / 300 份，并提升合作报价。最多一单需求 96 份，不超过初始容量；可把库存搬回餐架给客人，不能一键散卖换钱。合作和库存搬运不计入普通订单或急单，顾客实际拿到餐时才计数。
- 6 个长期目标覆盖首次合作、多种食品、声望、全菜单、扩建和综合经营，奖励金币与研究点；目标只能领取一次。每种食品显示库存和累计合作发货数，方便安排补货。
- 仓储、合作历史、声望、出货模式及领奖状态均写入原浏览器存档。旧存档自动补充空白合作记录；练习工坊仍完全隔离，不操作真实库存。

## 新食物与新手练习

- 共 8 种可手工制作或自动生产的成品，每种都有独立生成素材，沿用 Q 弹反馈；手作和机器的配方辅料均免费。
- 面团 → 曲奇烤炉 → 饼干，产线开放后可建；面团 → 小蒸笼 → 奶香包，第 1 单后开放；面团 → 蛋糕工台 → 草莓蛋糕，橙汁 → 冰棒冷柜 → 冰棒，第 2 单后开放。面团和果汁可用分流器制作支线。
- 配方手册展示全部 8 条路线、基础售价和解锁条件。前 4 张订单后新增 4 张新品订单，此后轮换全部食品；旧存档已接的订单原样保留，领取后才切换新版目录。已接急单不变。
- 第一次开始经营会进入独立的新手练习：做面包、等出炉、取餐、给顾客送餐、完成首单。小卡片和高亮按钮引导真实操作，不使用遮挡画布的大弹窗。
- 练习可以随时跳过、重练；主菜单「新手练习」与帮助页「跟着练一次」可重播。练习暂停正式工坊的生产与急单计时，不花正式金币、不保存练习布局；退出或刷新回到原工坊，老玩家不会被强制教学。

## 主菜单、急单与研究

- 启动先进入主菜单：开始 / 继续经营、急单与研究、配方手册、游戏设置。工坊左上角招牌可保存并返回菜单。菜单内不生产，且不会穿透建造、旋转或删除操作。
- 急单三选一，随主订单解锁早餐、甜点、双拼和三线协作等 9 种基础挑战，完成多次后增加需求。只统计接单后的成品销售，普通收入与主订单进度照常保留。轻松单适合初始产线，产能单需要升级或多条流水线。
- 达标领取额外金币与 1–3 个研究点。超时或放弃不扣金币；达标待领奖不会过期。同一时间只可接受一个急单。使用模拟时间计时，2 倍速同时加快生产和倒计时；菜单、弹窗、后台及暂停时均停止计时。
- 永久研究分为高效加工（每级 +15% 速度）、轻快运输（每格 0.4 → 0.3 → 0.2 → 0.1 秒）和精品包装（每级售价 +10%，按件取整）。每条最多 3 级，分别花费 1 / 2 / 3 点；升级保留正在加工的完成比例。
- 重开需要确认，先备份、保存成功才替换工坊；主菜单可恢复重开前的存档。研究、急单与设置都会保存。旧版存档自动补充空的研究记录，不重置设备、金币或进度。

## 视野与 Q 弹反馈

- 画布铺满窗口，没有常驻侧栏。订单、设备详情默认收起；建造卡片按需展开，选中后自动收起。打开面板只覆盖局部，不缩小画布或重置视角。
- 默认取景约 10×6 格，扩建后保持机器可操作大小。滚轮或加减按钮缩放，✥ 模式或鼠标中键拖动，百分比按钮返回起步区；地图可定位远处产线，⛶ 进入可拖动的纯净视野。
- 放置设备有落地压扁和阻尼回弹，加工有节奏挤压，货物跳动前进，出货和升级有局部粒子及金币反馈。反馈不晃动镜头、不改变生产速度，不进入存档。
- 暂停后仍可编辑布局。帮助内可以关闭 Q 弹；默认尊重系统“减少动态效果”设置。平板/手机使用单指放置，多指触摸会取消待放置操作，不支持双指捏合。

## 传送带连接

- 选中传送带工具，可以从旧传送带继续拖线；转弯会调整上一格出口，只为新增格子付费。
- 接入已有的侧向传送带时保留它的下游方向；明确拖过相对的传送带，会将其改为本次拖线方向。可拖过机器并沿它的既有出口继续铺，只有出货站会结束本次拖线。
- 拉错机器方向时保留最后有效格，不必松手，改沿出口拖动即可继续；快速斜拖优先经过固定设备的出口，不会自动旋转机器或清空原料。
- 箭头是出口，不能同时进料；两条出口相对的带子不会来回传货。分流器有两个出口，合流器可从其他三侧进料，出货站四侧均可接入。
- 轨道按实际接口绘制，转角不多画接口；方向不通的相邻端口用短红线标识。运输、拖线和绘制共用 `src/factory-links.js`。
- 机器、料斗和出货站的有效连接都有接驳段，延伸至格边并与传送带对齐。接口固定在底座上，不随机身 Q 弹缩放；邻居旋转或拆除时即时重算。
- 旧存档不重置。旧布局若从机器出口侧喂料，需要旋转机器或改从其他侧接入。

自动测试涵盖零金币完整开店流程、8 条食品链、降收益 / 涨运输价格、员工竞争取餐、过期顾客保餐、满架回收解困、旧存档和旧急单兼容、角色任务中途保存、1500 步混合操作逐步恢复、骨骼父子变换、仓储并发容量、合作防重领、960 格地图、小地图、练习隔离、菜单重开恢复和触摸取消。键盘和指针交互在模拟环境验证，尚未做真实浏览器视觉验收。
