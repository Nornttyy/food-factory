# 美食工坊

奶油色食品自动化游戏：连接多条生产线，让面包、甜甜圈和果汁自动出货。

[打开游戏](https://nornttyy.github.io/food-factory/) · [GitHub 仓库](https://github.com/Nornttyy/food-factory)

## 玩法

- 自由放置设备，拖动铺传送带，支持分流、合流与多条产线。
- 面粉 → 和面 → 烘烤，制作面包；订单解锁甜甜圈和橙汁。
- 成品自动出售，领取订单奖励，升级机器并扩建地块。
- 初始赠送设备可免费收回重放，拆除清空物品；付费设备退回实付费用。
- 堵塞停工、不丢料；支持暂停、2 倍速和浏览器自动存档。没有离线收入。

## 主菜单、急单与研究

- 启动先进入主菜单：开始 / 继续经营、急单与研究、配方手册、游戏设置。工坊左上角招牌可保存并返回菜单。菜单内不生产，且不会穿透建造、旋转或删除操作。
- 急单三选一，随主订单解锁早餐、甜点、双拼和三线协作等 9 种基础挑战，完成多次后增加需求。只统计接单后的成品销售，普通收入与主订单进度照常保留。轻松单适合初始产线，产能单需要升级或多条流水线。
- 达标领取额外金币与 1–3 个研究点。超时或放弃不扣金币；达标待领奖不会过期。同一时间只可接受一个急单。使用模拟时间计时，2 倍速同时加快生产和倒计时；菜单、弹窗、后台及暂停时均停止计时。
- 永久研究分为高效加工（每级 +15% 速度）、轻快运输（每格 0.4 → 0.3 → 0.2 → 0.1 秒）和精品包装（每级售价 +10%，按件取整）。每条最多 3 级，分别花费 1 / 2 / 3 点；升级保留正在加工的完成比例。
- 重开需要确认，先备份、保存成功才替换工坊；主菜单可恢复重开前的存档。研究、急单与设置都会保存。旧版存档自动补充空的研究记录，不重置设备、金币或进度。

## 视野与 Q 弹反馈

- 画布铺满窗口，没有常驻侧栏。订单、设备详情默认收起；建造卡片按需展开，选中后自动收起。打开面板只覆盖局部，不缩小画布或重置视角。
- 默认按已经开放的工坊区域取景，不为尚未解锁的地块缩小所有设备。滚轮或加减按钮缩放，✥ 模式或鼠标中键拖动，百分比按钮恢复构图；⛶ 进入可拖动的纯净视野。
- 放置设备有落地压扁和阻尼回弹，加工有节奏挤压，货物跳动前进，出货和升级有局部粒子及金币反馈。反馈不晃动镜头、不改变生产速度，不进入存档。
- 暂停后仍可编辑布局。帮助内可以关闭 Q 弹；默认尊重系统“减少动态效果”设置。平板/手机使用单指放置，多指触摸会取消待放置操作，不支持双指捏合。

## 传送带连接

- 选中传送带工具，可以从旧传送带继续拖线；转弯会调整上一格出口，只为新增格子付费。
- 接入已有的侧向传送带时保留它的下游方向；明确拖过相对的传送带，会将其改为本次拖线方向。可拖过机器并沿它的既有出口继续铺，只有出货站会结束本次拖线。
- 拉错机器方向时保留最后有效格，不必松手，改沿出口拖动即可继续；快速斜拖优先经过固定设备的出口，不会自动旋转机器或清空原料。
- 箭头是出口，不能同时进料；两条出口相对的带子不会来回传货。分流器有两个出口，合流器可从其他三侧进料，出货站四侧均可接入。
- 轨道按实际接口绘制，转角不多画接口；方向不通的相邻端口用短红线标识。运输、拖线和绘制共用 `src/factory-links.js`。
- 机器、料斗和出货站的有效连接都有接驳段，延伸至格边并与传送带对齐。接口固定在底座上，不随机身 Q 弹缩放；邻居旋转或拆除时即时重算。
- 旧存档不重置。旧布局若从机器出口侧喂料，需要旋转机器或改从其他侧接入。

64 项自动测试涵盖生产、旧存档迁移、急单截止与领奖、研究成本与实际速度、菜单冻结与操作隔离、重开备份失败与恢复、八种转角、机器接口几何、连续铺设、视角映射、触摸取消、弹性反馈边界及发布缓存版本一致性。键盘和指针交互在模拟环境验证，尚未做真实浏览器视觉验收。

## 试玩与验证

```sh
npm start
# http://localhost:8766
npm test
npm run build
```

生成的静态网页在 `dist/`。GitHub Pages 使用 `main` 分支根目录发布，`.nojekyll` 保持原生静态文件不经模板处理。所有运行资源使用相对路径，兼容 `/food-factory/` 项目子路径。
进度保存在当前浏览器的当前网站中。本地试玩和 GitHub 网址不自动共享存档，原本地进度仍保留在本地试玩网址。
推荐横屏；R 旋转，空格暂停，Esc 退出纯净视野或切回选择。画布聚焦时可用方向键选格、Enter 放置，移出当前视角的格子会自动带入视野。

## 素材

34 个独立裁切部件：9 台机器、16 种食品/原料、9 个运输及地面部件，采用内置图片生成制作的奶油色简洁卡通画风，不用真实纹理。素材保留原始透明通道及裁切坐标。

图集在 `assets/generated/factory/cream-v1/`，[原始提示词](assets/generated/factory/cream-v1/PROMPTS.md)。运行时传送轨道使用精确网格连接几何，生成图片用于机器、食品和物流卡片。未沿用带旧名称的分享封面。

网站[分享封面](public/og.png)使用内置图片生成功能制作，[最终提示词与生成记录](public/og-prompt.md)。主菜单沿用此插画，工坊画面仍由实时游戏绘制。

模拟核心在 `src/factory-core.js`，相机与弹性函数在 `src/factory-feel.js`，绘制在 `src/factory-renderer.js`，操作及存档在 `src/factory-main.js`。当前是网页原型，尚未移植微信小游戏运行环境；未进行微信真机检查。
